🚀 WORKFLOW AUTOMATION

When user clicks "Publish":

1. Token Dialog
   ├─ Input GitHub token (first time only)
   └─ Validate with GitHub API

2. Repository Selection
   ├─ List user's repositories
   └─ Option to create new repo

3. Upload & Configure
   ├─ Upload notebook to repository
   ├─ Create .github/workflows/publish.yml
   ├─ Enable GitHub Pages
   └─ Trigger GitHub Actions

4. Automatic Deployment
   └─ repo2jupyterlite-action builds JupyterLite site
   └─ Published to: https://username.github.io/repo-name/
