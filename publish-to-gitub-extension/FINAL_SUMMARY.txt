🚀 NEXT STEPS (15 minutes to local demo)

1. Install dependencies:
   npm install

2. Build TypeScript:
   npm run build

3. Build JupyterLite:
   jupyter lite build --extensions src/

4. Run locally:
   cd _build/html
   python -m http.server 8080

5. Open browser:
   http://localhost:8080
   → Open notebook
   → Click "Publish"
   → Done!
